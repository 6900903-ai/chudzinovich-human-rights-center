# Original-content growth plan

Technical SEO is only the foundation. CHUDO search growth should be driven by useful original work built from verifiable public evidence.

## Recurring publication families

- monthly Belarus political-repression chronology;
- quarterly detention, trial and sentencing review;
- prison and detention-facility reference updates;
- Criminal Code article explainers linked to documented cases;
- correction and source-change digest;
- guides for families, letter writers, journalists and researchers;
- methodology notes explaining difficult identity or status decisions without exposing private review data.

## Minimum standard for an original report

Every report should include a clear question, scope and time period; named author or responsible organization; publication and update dates; methodology; source list; distinction between source claims and CHUDO conclusions; limitations; correction route; stable canonical URL; and a concise summary that is useful without repeating third-party text.

## Prohibited growth shortcuts

- publishing thousands of thin auto-generated pages;
- indexing source mirrors merely to increase URL count;
- copying full third-party articles without rights;
- fabricating authors, reviews, citations, dates or endorsements;
- buying links or exchanging links for ranking manipulation;
- assigning political-prisoner status from a media mention alone.
