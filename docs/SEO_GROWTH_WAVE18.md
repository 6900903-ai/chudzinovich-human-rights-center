# Wave 18 — SEO growth foundation

This wave improves organic discoverability without using deceptive ranking techniques or third-party visitor tracking.

Implemented:
- stronger query-aligned titles and descriptions for core Belarus human-rights pages;
- Organization, WebSite, SearchAction and BreadcrumbList structured data;
- NewsArticle structured data for published news pages;
- Open Graph site metadata and locale tags;
- same-origin RSS feeds for RU/BE/EN/PL;
- sitemap `lastmod` for dated article pages;
- no Google Analytics / Tag Manager dependency.

Search-ranking note: technical SEO enables crawling and relevance but does not guarantee a specific Google position. Long-term ranking also depends on useful fresh content, authority, external references, crawl/index status and user demand.
