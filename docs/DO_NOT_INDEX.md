# Pages intentionally excluded from search indexing

The following classes remain public for navigation and source transparency but are intentionally `noindex,follow`:

- source-only Telegram and media news detail pages;
- individual Telegram channel archives;
- individual media source archives;
- news pagination, source-kind listings and month archives;
- empty people, former-prisoner, repression and prison catalogs before a real published snapshot exists;
- internal search results.

These exclusions protect index quality and do not remove the pages from the public website.
