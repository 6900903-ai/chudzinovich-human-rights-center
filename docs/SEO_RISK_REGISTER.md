# Search risk register

| Risk | Control |
|---|---|
| Thin or duplicate source pages dilute index quality | Source-only details and derivative archives stay `noindex,follow` |
| Empty database pages appear as soft 404s | Canonical database catalogs stay noindex until a real snapshot is published |
| Search snippets misrepresent source claims | High-value metadata describes provenance and verification boundaries |
| Brand identity is inconsistent | Organization/WebSite schema and stable image assets use one CHUDO identity |
| Tests mutate the deployed artifact | A fresh final build runs after tests and the exact artifact is validated |
| Search Console token is fabricated | Verification remains an explicit owner-supplied gate |
| Automated content is mistaken for original reporting | Editorial policy distinguishes source material from CHUDO conclusions |
| Ranking work encourages unsafe publication | SEO targets cannot reward unsupported status claims or private data exposure |
