# Remaining external gates

The following cannot be closed by repository code alone:

1. A real, legally cleared and privately reviewed Viasna export or equivalent canonical source snapshot.
2. Human resolution of identity conflicts and high-risk claims.
3. Rights clearance for third-party portraits.
4. Google Search Console verification using the domain owner's actual token.
5. Original CHUDO reports and external citations earned through useful work.

The technical search foundation should remain fail-closed until each relevant gate has real evidence.
