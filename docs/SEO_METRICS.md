# Search metrics

Track search performance by useful page class rather than raw URL count.

## Weekly

- indexed CHUDO-owned hub and policy pages;
- impressions, clicks, click-through rate and average position by query group;
- canonical and duplicate exclusions;
- crawled-not-indexed and soft-404 trends;
- live monitor availability;
- corrections received from search visitors.

## Monthly

- original reports published;
- verified canonical person and prison records added or materially updated;
- reputable external citations earned;
- branded versus non-branded search growth;
- language coverage and query gaps;
- Core Web Vitals field data when enough traffic exists.

No target should reward publishing unreviewed personal data, duplicate source pages or unsupported status claims.
