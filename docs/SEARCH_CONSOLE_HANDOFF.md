# Search Console owner handoff

The repository is prepared to expose a sitemap index at:

`https://chudzinovich.pp.ua/sitemap-index.xml`

A Google Search Console verification token is account-specific and must come from the verified domain owner. The project must not guess, synthesize or copy a token from another property.

Once a real token is available, add it through the DNS provider or the exact verification method selected in Search Console, verify the HTTPS domain property, submit the sitemap index and retain the verification record outside public editorial data.
