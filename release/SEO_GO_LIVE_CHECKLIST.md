# Search go-live checklist

- [ ] Exact final Pages artifact validation passes.
- [ ] Homepage returns HTTPS 200 and is indexable.
- [ ] `sitemap-index.xml`, `sitemap.xml`, `news-sitemap.xml` and `robots.txt` return HTTPS 200.
- [ ] Organization and WebSite structured identity is present on all four homepages.
- [ ] Editorial policy is public, indexable and linked from every page.
- [ ] Social preview PNG is 1200×630 and publicly reachable.
- [ ] Empty canonical database sections remain noindex.
- [ ] Source-only and derivative pages remain noindex.
- [ ] First real public snapshot has passed legal, privacy, source and identity review.
- [ ] Search Console verification uses an owner-provided token.
- [ ] Sitemap index is submitted after the domain property is verified.
- [ ] Original reports and canonical records include sources, dates and correction history.
